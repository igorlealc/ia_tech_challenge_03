# Commits And Language

- Codigo, nomes de classes, metodos e arquivos devem usar ingles.
- Textos visiveis ao usuario podem usar portugues por ser o idioma do trabalho.
- Commits devem ser pequenos, descritivos e focados em uma mudanca.
- Prefira mensagens de commit em portugues quando acompanharem o restante do
  trabalho academico.
- Documente TODOs tecnicos quando houver contrato externo pendente, como o
  backend real de IA.
