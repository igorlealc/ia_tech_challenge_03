Resumo Executivo

A entrega da Fase 3 implementa uma aplicação local integrada para apoiar, em caráter acadêmico, a interpretação de casos clínicos relacionados a rastreamento ou investigação mamária. O usuário interage em linguagem natural por um chat Flutter Web; o backend organiza o fluxo com LangGraph, consulta uma LLM local com adapter LoRA e aciona uma API de inferência quando há dados suficientes para estimar a classe positiva do alvo TARGET_CANCER_MAMA_PROVAVEL.

O sistema não realiza diagnóstico, não prescreve condutas e não substitui avaliação médica. Todas as respostas incluem aviso de uso acadêmico e o fluxo registra auditoria local para rastreabilidade.
Python FastAPI LangGraph LangChain MLX LoRA Flutter Web Docker Compose

Arquitetura da Solução

A arquitetura separa a experiência de chat, a orquestração da IA e a inferência supervisionada. Essa divisão facilita demonstração local, auditoria e substituição futura de componentes.

01 Flutter Web
Médico escreve um caso ou pergunta clínica em texto livre.
02 Assistant API
FastAPI recebe POST /chat/messages e inicia o grafo.
03 LangGraph + LLM
Decide se há caso preditivo, extrai dados e gera resposta em PT-BR.
04 ML API
Random Forest retorna classe e probabilidade da classe positiva.
05 Resposta auditada
Resultado é interpretado com fontes, ressalvas e log local.

Componentes

fe/ Aplicação Flutter Web com rota única, tela de chat, envio HTTP ao assistant e aviso de uso acadêmico na interface.
assistant/ Backend de IA com FastAPI, LangGraph, prompts de segurança, chamadas MLX e ferramenta de inferência preditiva.
ml/ API FastAPI que carrega random_forest.joblib, valida schema e expõe endpoints de saúde, metadados e predição.

Processo de Fine-tuning

O fine-tuning usa o dataset PubMedQA como base médica acadêmica. O script de preparação lê fine-tuning/data/ori_pqal.json, transforma cada item em mensagens no formato conversacional e divide os dados em treino e validação com semente fixa.

Preparação dos dados O arquivo 1_preparar_dataset.py constrói prompts com contexto, pergunta e resposta esperada, embaralha os exemplos e gera train.jsonl e validation.jsonl.
Treinamento LoRA O arquivo 2_treinar_modelo.py executa mlx_lm.lora sobre mlx-community/Llama-3.2-3B-Instruct-4bit, salvando o adapter em fine-tuning/adapters/llama3_2_3b_pubmedqa. 
./fine_tuning.sh

# Etapas principais:
python fine-tuning/1_preparar_dataset.py
python fine-tuning/2_treinar_modelo.py

O objetivo do adapter é especializar o comportamento do LLM para perguntas biomédicas contextualizadas, mantendo a execução local em Apple Silicon por meio de MLX.

Assistente Médico Criado

O assistente atua como camada intermediária entre linguagem natural e ferramentas estruturadas. Ele decide quando chamar o modelo preditivo, extrai um payload clínico, converte esse payload em 24 features técnicas e interpreta a resposta para o usuário.

Decisão de uso do modelo O grafo usa termos explícitos, contexto mamário e idade; quando configurado, também chama a LLM para decidir se o Random Forest deve ser consultado.
Extração e transformação A LLM extrai campos como idade, sexo, raça/cor, mamografia prévia, risco elevado e indicação. O código converte isso para o schema do modelo supervisionado.
Ferramenta preditiva A tool prever_risco_cancer_mama faz chamada HTTP para ML_API_URL/predict com as features estruturadas.
Resposta final O prompt final pede interpretação da classe, da probabilidade da classe positiva e das limitações, sem expor JSON ou features internas ao usuário.

Modelo Preditivo Random Forest

A API de ML encapsula o modelo do trabalho anterior, treinado a partir de dados SISCAN/DATASUS. Ela carrega o bundle ml/model/random_forest.joblib, preservando nomes das features, classe positiva, coluna alvo e métricas globais.

Accuracy0.760875
Recall0.424779
F10.130850
Precision0.077336
ROC AUC0.628885
Balanced Acc.0.600263
A probabilidade retornada pela API é a estimativa de predict_proba para a classe positiva do modelo. Ela não deve ser interpretada como probabilidade clínica diagnóstica real nem como métrica global de acerto.

Hiperparâmetros exportados: n_estimators=100, max_depth=8, min_samples_leaf=10 e class_weight=balanced.

Segurança, Validação e Explainability

Limites clínicos O prompt de sistema proíbe diagnóstico definitivo e prescrição. O rodapé obrigatório informa: "Uso acadêmico; não substitui avaliação clínica."
Validação de entrada O chat usa Pydantic com tamanho máximo de mensagem, papéis permitidos e contratos explícitos para requisição e resposta.
Auditoria Cada execução registra decisão, payload clínico, features, tool chamada, retorno do modelo, fontes, erros e aplicação do aviso.

Campos registrados no log

  • should_use_predictive_model e motivo da decisão.
  • clinical_payload extraído da mensagem do médico.
  • features enviadas ao Random Forest.
  • tool_result com predição, probabilidade e métricas.
  • sources e indicador de aplicação do aviso de segurança.

Interface Web

O frontend foi implementado em Flutter Web como uma aplicação de chat de tela única. Ele consome POST /chat/messages, apresenta mensagens do médico e do assistente, permite limpar a conversa e exibe aviso acadêmico fixo na base da tela.

Estrutura A implementação segue separação por feature, com domínio, repositórios, DTOs, cliente HTTP, presenter e widgets de apresentação.
Distribuição O build Docker serve o Flutter Web via Nginx e recebe API_BASE_URL por argumento de build.

A avaliação combina métricas do modelo supervisionado, verificação de integração local e evidências de auditoria. A API de ML expõe /metadata com métricas e schema, enquanto o assistant registra os resultados das chamadas em assistant/logs/audit.jsonl.

Limitações e Próximos Passos

Limitações atuais Dados e protocolos são acadêmicos; o modelo supervisionado tem baixa precision; a extração de texto livre pode falhar; a aplicação não integra prontuário real nem autenticação.
Evoluções recomendadas Adicionar base vetorial de protocolos internos, autenticação, testes end-to-end, avaliação formal da LLM, calibração do modelo e validação clínica supervisionada.
